# Provenance

This directory is a pinned, verbatim copy of `skills/i-have-adhd/` from
[ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd), taken at commit
[`839872f9d1cd634fed642b4589ce7226199cc15f`](https://github.com/ayghri/i-have-adhd/commit/839872f9d1cd634fed642b4589ce7226199cc15f)
(2026-09-19).

`SKILL.md` and `LICENSE` (MIT) are unmodified. vam bundles them here and, on
request from the operator's Settings screen (`src/renderer/settings/
AdhdSkillCard.tsx`), writes both files unchanged into an agent's own skills
directory — never a rewording, never a summary. See
`src/main/skills/adhd-skill.ts` for what "on request" does and does not do.

This `NOTICE.md` file itself is not part of the upstream skill and is not
written to an installed skill directory; it exists only so a reader of this
repository's tree can see where the copy came from without opening the app.
